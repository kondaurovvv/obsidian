## Основные типы топологий

### 1. **Шина (Bus)** - устаревшая

Все устройства подключены к одному общему кабелю (магистрали).

```
[ПК1] ---+--- [ПК2] ---+--- [ПК3] ---+--- [ПК4]
          |             |             |
      (терминатор)  (терминатор)
```

**Плюсы:** мало кабеля, простота.  
**Минусы:** если кабель оборван — вся сеть падает, низкая скорость при большом количестве узлов.  
**Где используется:** почти не используется (раньше в Ethernet на коаксиальном кабеле).

---

### 2. **Звезда (Star)** - самая популярная

Все устройства подключены к одному центральному устройству (коммутатору/маршрутизатору).

```
        [ПК1]
           |
[ПК2] --- [SWITCH] --- [ПК3]
           |
        [ПК4]
```

**Плюсы:** легко найти обрыв, высокая отказоустойчивость (выход одного ПК не влияет на других).  
**Минусы:** требуется больше кабеля, при выходе из строя центрального устройства сеть падает полностью.  
**Где используется:** 99% современных сетей (домашние, офисные).

---

### 3. **Кольцо (Ring)**

Каждое устройство соединено с двумя соседними, образуя замкнутое кольцо.

```
   [ПК1] --- [ПК2]
    |            |
   [ПК4] --- [ПК3]
```

**Плюсы:** данные передаются быстро, нет коллизий.  
**Минусы:** обрыв одного соединения или выход из строя одного ПК нарушает всю сеть.  
**Где используется:** устаревает, но встречается в некоторых технологиях (FDDI, Token Ring, SONET/SDH в оптике).

---

### 4. **Полносвязная (Mesh)**

Каждое устройство соединено с каждым другим напрямую.

```
   [ПК1] ====== [ПК2]
    ||  \      /  ||
    ||   ======   ||
    ||  /      \  ||
   [ПК3] ====== [ПК4]
```

**Плюсы:** максимальная отказоустойчивость (можно обходить поврежденные узлы).  
**Минусы:** очень много кабеля и портов, дорогостоящая.  
**Где используется:** в критически важных сетях (дата-центры, военные, спутниковая связь), в интернете — на уровне магистральных маршрутизаторов.

---

### 5. **Ячеистая (Partial Mesh)**

Гибрид: не все соединены со всеми, но есть несколько резервных маршрутов.

```
   [ПК1] ---- [ПК2]
    |  \      / |
    |   ======  |
    |  /      \ |
   [ПК3] ---- [ПК4]
```

**Плюсы:** хороший баланс между надежностью и стоимостью.  
**Где используется:** крупные корпоративные сети, интернет-провайдеры.

---

### 6. **Дерево (Tree / Hierarchical)**

Иерархическая структура, где устройства группируются в "звезды", соединенные последовательно.

```
      [КОРНЕВОЙ SW]
        /    |    \
    [SW1]  [SW2]  [SW3]
     / \    / \    / \
    ПК ПК  ПК ПК  ПК ПК
```

**Плюсы:** масштабируемость, легко управлять большими сетями.  
**Минусы:** выход из строя родительского узла отключает целую ветку.  
**Где используется:** большие корпоративные сети, интернет-провайдеры, иерархические структуры.

---

### 7. **Шина с пассивным концентратором (Hub)**

Фактически это "звезда" физически, но "шина" логически (данные от одного узла идут всем через хаб). Это **устаревший вариант**, сейчас используют коммутаторы (switch), которые работают умнее.

---

## Смешанные топологии (гибриды)

В реальных сетях редко используют чистый вид. Чаще всего это комбинация:

- **Звезда-кольцо** (кольцо из свичей, к каждому свичу — свои звезды).
    
- **Дерево-звезда** (иерархическая структура).
    
- **Mesh + Star** (на уровне магистрали — ячеистая, на уровне доступа — звезды).
