**Open vSwitch (OVS)** — это ==программный многоуровневый виртуальный коммутатор с открытым исходным кодом==. Он используется в средах виртуализации и облачных платформах (таких как Proxmox, KVM, OpenStack) для маршрутизации трафика между виртуальными машинами, контейнерами и физическими сетями.

Основные возможности и компоненты

- **Гибкость настройки:** OVS поддерживает стандарты 802.1Q (VLAN), QoS, агрегацию каналов (LACP) и туннелирование (VXLAN, GRE).
- **Программно-определяемые сети (SDN):** Поддержка протокола OpenFlow позволяет централизованно управлять маршрутизацией трафика и настраивать правила обработки пакетов для всей сети.
- **Компоненты архитектуры:** Состоит из управляющего демона (`ovs-vswitchd`), базы данных состояния (`ovsdb-server`) и модуля ядра, обеспечивающего быструю передачу данных.

Где применяется

В отличие от стандартного Linux-бриджа, OVS обеспечивает распределенную коммутацию между серверами и глубокую интеграцию с системами оркестрации, выступая свободно распространяемым аналогом коммерческих решений вроде Cisco Nexus 1000v.

## Команды Open vSwitch

Установка.

```bash
apt install -y openvswitch-switch
```

Создание бриджа OVS.
```
sudo ovs-vsctl add-br <имя бриджа (docker-ovsbr1)>

```

Назначить бриджу ip и маску подсети, а так же включить интерфейс.
```
sudo ifconfig docker-ovsbr1 172.25.0.1 netmask 255.255.255.0 up
```

Показать информацию о бриджах.
```
sudo ovs-vsctl show
```
