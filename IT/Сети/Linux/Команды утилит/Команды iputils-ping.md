Отправляет ICMP-эхо-запросы на указанный узел (бесконечно, пока не нажать Ctrl+C). Проверяет доступность хоста, измеряет время ответа (RTT) и потери пакетов.
```bash
ping <IP адрес удаленного узла>
```

То же самое, но отправляет ровно указанное количество запросов (например, -c 5) и после этого завершается, показывая статистику.
```bash
ping <IP адрес удаленного узла> -c <количество запросов>
```

```bash
ping [опции] <IP-адрес или доменное имя целевого узла>

-4 — использовать только протокол IPv4;
-6 — использовать только протокол IPv6;
-i — интервал между отправкой ICMP пакета;
-A — согласовать время между отправками ICMP-пакетов ко времени задержки между отправкой и получением ICMP-пакетов;
-с — количество отправляемых ICMP-пакетов;
-s — размер ICMP-пакета в байтах;
-n — не выполнять преобразование имен узлов получателя и отправителя.
```
