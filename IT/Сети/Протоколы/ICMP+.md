**ICMP** (Internet Control Message Protocol) — это ==служебный протокол сети (уровня IP), который используется для диагностики соединений и передачи сообщений об ошибках==. Он не передаёт сами пользовательские данные, а помогает маршрутизаторам и компьютерам сообщать о проблемах (например, если узел недоступен). 

- Internet Control Message Protocol;
- RFC 792, неотъемлемая часть IPv4;
- Сервисный протокол без контроля доставки;
- Не передает пользовательских данных.
