**DHCPv6** — это ==сетевой протокол для автоматической настройки устройств в сетях [IPv6]==. Он раздает компьютерам и телефонам IP-адреса, адреса серверов DNS и другие важные параметры, работая похожим на старый добрый DHCP для IPv4 образом.

#### Отличия DHCPv4 и DHCPv6
- Не используется вложение в BOOT;
- Вместо широковещательной рассылки используется групповая:
	- FF02::1:2 - все DHCPv6 серверы и агенты;
	- FF05::1:3 - все DHCP - серверы предприятия (сайта);
- Используются UDP-порты 546 (клиент) и 547 (сервер).

#### Stateful и Stateless режим
- Stateful DHCPv6 - режим с сохранением состояния клиентов:
	- Сервер ведет базу выдаваемых адресов;
	- Вместе с адресом клиент получает необходимые настройки;
	- Сервер выбирает адрес, время аренды, и настройки для каждого клиента;
- Stateless DHCPv6 - режим без сохранения состояния клиентов:
	- Клиент подключается к серверу, уже имя действительный адрес;
	- Сервер отдает только дополнительные настройки, нужные для работы в сети.
