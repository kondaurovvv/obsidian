- Из исходных кодов:
	- Плюсы:
		- Возможность модифицировать ПО;
		- Возможность установки без прав администратора.
	- Минусы:
		- Поиск зависимостей очень долгий;
		- Отсутствует контроль установленного ПО.

- Из пакетов:
	- Плюсы:
		- Сразу виден перечень зависимостей;
		- Есть контроль установленного ПО.
	- Минусы:
		- Для установки нужны права администратора;
		- Пакеты создаются под определенный дистрибутив Linux.

Репозиторий - это место, где хранятся и поддерживаются какие-либо данные. Чаще всего данные в репозитории хранятся в виде файлов, доступных для дальнейшего распространения по сети.
- Из репозитория:
	- Плюсы:
		- Сразу виден перечень зависимостей;
		- Есть контроль установленного ПО;
		- Как правило, все зависимости автоматически устанавливаются из репозитория.
