Выводит краткую справку по всем доступным опциям утилиты.
```bash
ethtool
```
 
 Выводит текущие настройки и состояние сетевого интерфейса.
```bash
ethtool <имя адаптера>
```

 Показывает текущие параметры адаптера: скорость, дуплекс, автосогласование, статус соединения (Link detected) и поддерживаемые режимы.
```bash
ethtool <имя интерфейса>
```
