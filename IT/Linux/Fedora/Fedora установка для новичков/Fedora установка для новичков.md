#### Установка
![[F-1.png|900]]
Выбираем **"Test this media & start Fedora-Workstation-Live"** -  красивый интерфейс с мышкой.
Жмем **"Enter"**.

![[F-2.png|900]]
Жмем **"Install Fedora Linux..."**.

![[f-3.png|900]]
Выбираем язык и раскладку клавиатуры.
Жмем **"Next"**.

![[f-4.png|900]]
Выбираем диск для установки и выбираем **"How would you like to install"?**.
Жмем **"Next"**.


![[f-5.png|900]]
Жмем **"Next"**.

| Элемент экрана                | Что это                                                                                                                                                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Encrypt my data** (чекбокс) | Опция шифрования диска. Если поставить галочку — все новые разделы будут зашифрованы с помощью LUKS. При загрузке системы потребуется вводить пароль шифрования.                                                 |
| **Пояснительный текст**       | _"Secure your data using disk-based encryption. Only applies to new partitions"_ — предупреждение, что шифрование применяется только к разделам, которые создаст установщик (существующие разделы не шифруются). |


![[f-6.png|900]]
Жмем **"Erase data and install"**.

| Раздел                       | Что это                                                                                                                                                                                                                                               |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **nvmeOn1p1**                | **BIOS Boot Partition** (раздел для загрузки в режиме BIOS). Размер — всего 1.05 МБ. Используется для хранения загрузчика GRUB при загрузке в старом режиме BIOS (не UEFI). Так как у вас виртуальная машина, установщик создал его на всякий случай. |
| **nvmeOn1p2**                | **Загрузочный раздел (/boot)**. Размер — 2.15 ГБ, отформатирован в **ext4**. Содержит ядро Linux, образы инициализации и другие файлы, необходимые для запуска системы. Монтируется в `/boot`.                                                        |
| **nvmeOn1p3 (корневой)**     | **Корневой раздел ( / )** в формате **Btrfs** (современная файловая система с поддержкой снимков). Размер — 40.8 ГБ. Здесь будет установлена сама Fedora, все системные файлы и программы.                                                            |
| **nvmeOn1p3 (подтом /home)** | **Подтом Btrfs для /home** — это не отдельный раздел, а логический подтом внутри того же раздела nvmeOn1p3. Размер — те же 40.8 ГБ (делит место с корневым). Здесь будут храниться ваши личные файлы, документы, загрузки, настройки пользователя.    |


![[f-7.png|900]]
Жмем **"Exit to live desktop"**.
В меню (верхний правый угол) выберите **выключение / перезагрузку**.
