Показывает все IP-адреса, назначенные на сетевые интерфейсы, вместе с их состоянием и дополнительной информацией (broadcast, scope и т.д.).
```bash
ip address (ip a)
```

Отображает список всех сетевых интерфейсов, их состояние (включен/выключен), MTU, MAC-адреса и флаги.
```bash
ip link
```

Выводит текущую таблицу маршрутизации (куда направлять пакеты для разных сетей, шлюз по умолчанию и т.п.).
```bash
ip route
```

Включает (поднимает) указанный сетевой интерфейс (например, eth0).
```bash
ip link set <имя интерфейса> up
```

Выключает (опускает) указанный сетевой интерфейс.
```bash
ip link set <имя интерфейса> down
```

Изменяет аппаратный MAC-адрес интерфейса eth0 на заданный (требует прав root и отключенного интерфейса).
```bash
ip link set dev eth0 address <новый MAC адрес>
```


```bash
ip address {add|change|replace} <ip адрес>/<маска в виде префикса> dev <имя интерфейса> -
```

```bash
ip address del <IP-адрес>/<маска> dev <имя_интерфейса> -
```
