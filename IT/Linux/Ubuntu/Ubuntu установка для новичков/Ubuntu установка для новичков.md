#### Установка
![[U-1.png|900]]
Выбираем **"Try or Install Ubuntu"** -  красивый интерфейс с мышкой.
Жмем **"Enter"**.

![[U-2.png|900]]
Выбираем язык.
Жмем **"Next"**.

![[U-3.png|900]]
Это экран настройки специальных возможностей для людей с ограниченными возможностями.
Жмем **"Next"**.

| Раздел                                         | Описание                                                                                                                           | Что можно настроить                                                                                                                                                                                                       |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Seeing** (Зрение)                            | Настройки для людей с нарушениями зрения. Позволяет сделать изображение на экране более удобным для восприятия.                    | — Экранный диктор (озвучивание текста на экране)  <br>— Увеличение масштаба экрана  <br>— Высокая контрастность (изменение цветовой схемы)  <br>— Крупный шрифт  <br>— Инверсия цветов                                    |
| **Hearing** (Слух)                             | Настройки для людей с нарушениями слуха. Позволяет заменить звуковые сигналы визуальными.                                          | — Визуальные оповещения (мигание окна или экрана вместо звукового сигнала)                                                                                                                                                |
| **Typing** (Печать)                            | Настройки для людей с нарушениями моторики или координации движений. Облегчает набор текста на клавиатуре.                         | — Залипание клавиш (зажатие клавиши-модификатора, например Shift, работает как удержание)  <br>— Медленные клавиши (задержка перед регистрацией нажатия)  <br>— Отскок клавиш (игнорирование случайных повторных нажатий) |
| **Pointing and clicking** (Указание и нажатие) | Настройки для людей, которым сложно управлять мышью. Позволяет управлять курсором с клавиатуры или изменять поведение кнопок мыши. | — Управление курсором с помощью цифровой клавиатуры (эмуляция мыши)  <br>— Изменение порядка кнопок мыши (для левшей)  <br>— Эмуляция щелчка правой кнопки мыши                                                           |
| **Zoom** (Масштабирование)                     | Настройка увеличительного стекла для экрана. Позволяет увеличивать отдельные участки экрана.                                       | — Включение/выключение увеличительного стекла  <br>— Настройка степени увеличения                                                                                                                                         |

![[U-4.png|900]]
Выбираем раскладку клавиатуры.
Жмем **"Next"**.

![[U-5.png|900]]
Выбираем **"Use wired connection"**.
Жмем **"Next"**.

| Элемент                                                          | Описание                                                                                                                                                                                                |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use wired connection** (Использовать проводное подключение)    | Подключение через сетевой кабель (Ethernet). Если кабель вставлен в компьютер, интернет появится автоматически.                                                                                         |
| **No Wi-Fi devices detected** (Wi-Fi устройства не обнаружены)   | Система не нашла встроенный или внешний Wi-Fi адаптер. Это может означать, что:  <br>— В компьютере нет Wi-Fi модуля  <br>— Требуются дополнительные драйверы (обычно для некоторых моделей Wi-Fi карт) |
| **Do not connect to the Internet** (Не подключаться к интернету) | Установка будет проходить без интернета. Система установит только базовый набор программ. Дополнительные драйверы и обновления не скачаются.                                                            |

![[U-6.png|900]]
Выбираем **"Install Ubuntu"**.
Жмем **"Next"**.

|Элемент|Описание|
|---|---|
|**Install Ubuntu** (Установить Ubuntu)|Полная установка системы на жесткий диск. Вы уже прошли все предыдущие шаги, и сейчас начнется процесс копирования файлов.|
|**Try Ubuntu** (Попробовать Ubuntu)|Загрузка Ubuntu в "живом" режиме (Live USB). Вы сможете ознакомиться с системой, не внося изменений на жесткий диск. Все изменения будут жить только в оперативной памяти и исчезнут после перезагрузки.|

![[U-7.png|900]]
Выбираем **"Interactive Installation"**.
Жмем **"Next"**.

|Элемент|Описание|
|---|---|
|**Interactive Installation** (Интерактивная установка)|Пошаговый режим с подсказками. Установщик будет задавать вопросы и вести вас через каждый этап. Самый простой и понятный способ.|
|**Automated with autoinstall file** (Автоматическая с файлом autoinstall)|Установка по заранее подготовленному файлу конфигурации (`autoinstall.yaml`). В этом файле уже прописаны все настройки (язык, разметка, пользователь и т.д.). Установка проходит без вопросов.|
|**Automated with Landscape** (Автоматическая через Landscape)|Установка с использованием сервера Landscape (корпоративное решение Canonical). Файл конфигурации автоматически загружается с сервера Landscape. Используется в крупных организациях для централизованного управления.|

![[U-8.png|900]]
Выбираем **"Default selection"**.
Жмем **"Next"**.

| Элемент                                    | Описание                                                                                                                                               |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Default selection** (Стандартный набор)  | Базовый набор программ: веб-браузер (Firefox) и основные утилиты. Только самое необходимое.                                                            |
| **Extended selection** (Расширенный набор) | Расширенный набор программ: офисные инструменты (LibreOffice), утилиты, веб-браузер. Все программы не требуют интернета для работы (offline-friendly). |

![[U-9.png|900]]
Ставим галочки:
- **"Install third-party software for graphics and Wi-Fi hardware"**
- **"Download and install support for additional media formats"**
Жмем **"Next"**.

| Элемент                                                                                                                     | Описание                                                                                                                                                              |
| --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Install third-party software for graphics and Wi-Fi hardware** (Установить стороннее ПО для графики и Wi-Fi)              | Установка проприетарных драйверов для видеокарт (NVIDIA, AMD) и Wi-Fi адаптеров. Может значительно улучшить производительность и стабильность работы оборудования.    |
| **Download and install support for additional media formats** (Скачать и установить поддержку дополнительных медиаформатов) | Установка кодеков для воспроизведения популярных мультимедийных форматов: MP3, MP4, MOV, и других. Без этого некоторые аудио и видео файлы не будут воспроизводиться. |

![[U-10.png|900]]
Выбираем **"Erase disk and install Ubuntu"**.
Жмем **"Next"**.

| Элемент                                                              | Описание                                                                                                                                          |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Erase disk and install Ubuntu** (Стереть диск и установить Ubuntu) | Система полностью очистит весь жесткий диск, удалит все данные (включая другие операционные системы) и установит Ubuntu как единственную систему. |
| **Manual Installation** (Ручная установка)                           | Для опытных пользователей. Вы сами размечаете диск, создаете разделы, указываете точки монтирования.                                              |

![[U-11.png|900]]
Выбираем **"No encryption"**.
Жмем **"Next"**.

|Элемент|Описание|
|---|---|
|**No encryption** (Без шифрования)|Данные на диске не шифруются. Если кто-то получит физический доступ к вашему компьютеру или жесткому диску, он сможет прочитать все ваши файлы.|
|**Encrypt with a passphrase** (Шифрование с парольной фразой)|Весь диск будет зашифрован. При каждом включении компьютера нужно будет вводить пароль для расшифровки. Без этого пароля систему не запустить.|
|**Use hardware-backed encryption** (Аппаратное шифрование)|Диск будет автоматически расшифровываться при загрузке с помощью аппаратного модуля (TPM). Вам не нужно вводить пароль при каждом включении.|
|**Advanced options** (Расширенные настройки)|Дополнительные настройки файловой системы. Для обычных пользователей не требуется.|

![[U-12.png|900]]
Вводим данные и оставляем галочку на **"Require my password to log in"**.
Жмем **"Next"**.

| Элемент                                                        | Описание                                                                                           |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Your name** (Ваше имя)                                       | Ваше полное имя. Будет отображаться на экране входа и в системе.                                   |
| **Your computer's name** (Имя вашего компьютера)               | Имя, которое будет видно в сети. Буквы, цифры и дефисы. **Без пробелов!**                          |
| **Your username** (Ваше имя пользователя)                      | Имя для входа в систему. **Только латинские буквы и цифры, без пробелов.**                         |
| **Password** (Пароль)                                          | Пароль для входа в систему. Придумайте надежный пароль.                                            |
| **Confirm password** (Подтвердите пароль)                      | Повторите пароль для проверки.                                                                     |
| **Show** (Показать)                                            | Галочка для отображения пароля в открытом виде (чтобы проверить, что правильно ввели).             |
| **Require my password to log in** (Требовать пароль для входа) | Если включено — при каждом входе нужно вводить пароль. Если выключено — вход будет автоматическим. |
| **Use Active Directory** (Использовать Active Directory)       | Вход через корпоративный домен Windows. Используется в компаниях.                                  |
