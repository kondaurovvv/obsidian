**Point-to-Point Protocol (PPP)** — это ==базовый протокол канального уровня==. Он позволяет устанавливать прямое соединение между двумя сетевыми узлами, передавать данные, шифровать их и проверять подлинность пользователя. Чаще всего он применяется для подключения компьютеров к интернету через различные типы сетей. 

Основные задачи и функции PPP:

- **Аутентификация:** перед началом передачи данных протокол проверяет логин и пароль, защищая сеть от несанкционированного доступа.
- **Инкапсуляция:** служит своеобразным «конвертом», позволяя упаковывать данные разных сетевых протоколов (например, IP) для передачи по одной линии.
- **Сжатие и обнаружение ошибок:** оптимизирует передаваемый трафик и проверяет целостность пакетов при доставке.

Важные разновидности

- **PPPoE (Point-to-Point Protocol over Ethernet):** передача кадров PPP через сети Ethernet. Широко используется интернет-провайдерами для организации доступа абонентов в сеть (например, по кабелю или DSL-модемам).
- **PPTP (Point-to-Point Tunneling Protocol):** туннельный протокол, который применялся для создания безопасных виртуальных частных сетей (VPN).
