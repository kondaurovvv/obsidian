#### Установка
![[D1.png|900]]
Выбираем **"Graphical install"** -  красивый интерфейс с мышкой.

![[D2.png|900]]
Выбираем язык.

![[D3.png|900]]
Выбираем страну.

![[D4.png|900]]
Выбираем раскладку клавиатуры.

![[D5.png|900]]
Вводим имя компьютера.

![[D6.png|900]]
Вводим имя домена или оставляем пустым если нет домена.

![[D7.png|900]]
Вводим пароль от **Root** пользователя.

![[D8.png|900]]
Вводим в поле **"Full name for the new user"** наше полное имя. (Ivan)

![[D9.png|900]]
Вводим в поле **"Username for your account"** короткое имя. (ivan)

![[D10.png|900]]
Вводим пароль от **ivan** пользователя.

![[D11.png|900]]
Выбираем часовой пояс.

![[D12.png|900]]
| Вариант | Описание | Для кого |
|---------|----------|----------|
| **Guided - use entire disk** | ✅ Стандартная разметка — система сама разобьёт диск на разделы (корневой, swap, /home) | **Для вас** — самый простой и надёжный |
| **Guided - use entire disk and set up LVM** | Гибкая разметка с LVM (можно изменять размеры разделов позже) | Для продвинутых пользователей |
| **Guided - use entire disk and set up encrypted LVM** | LVM + шифрование всего диска | Для тех, кому нужна максимальная безопасность |
| **Manual** | Ручная разметка (создание разделов вручную) | Для экспертов |
