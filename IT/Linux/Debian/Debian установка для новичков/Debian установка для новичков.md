| Вариант                                           | Описание                                                                                 |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Guided - use entire disk**                      | **Стандартная разметка** — система сама разобьёт диск на разделы (корневой, swap, /home) |
| Guided - use entire disk and set up LVM           | Гибкая разметка с LVM (можно изменять размеры разделов позже)                            |
| Guided - use entire disk and set up encrypted LVM | LVM + шифрование всего диска                                                             |
| Manual                                            | Ручная разметка (создание разделов вручную)                                              |

![[D14.png|900]]
Выбираем диск для установки "**All files in one partition**".
Жмем **"Continue"**.

| Вариант                            | Описание                                                           |
| ---------------------------------- | ------------------------------------------------------------------ |
| **All files in one partition**     | **Всё в одном разделе** (корневой `/` + `/home` внутри)            |
| Separate /home partition           | Отдельный раздел для домашних папок (удобно при переустановке)     |
| Separate /home, /var, and /tmp     | Разделение системных логов и временных файлов на отдельные разделы |
| Separate /var and /srv, swap < 1GB | Для серверов (веб-серверы, базы данных)                            |
| Small-disk (< 10GB)                | Оптимизация для маленьких дисков                                   |

![[D15.png|900]]
Показано, какие разделы будут созданы:
- **#1 primary (40.7 GB)** — корневой раздел `/` с файловой системой ext4;
- **#5 logical (2.2 GB)** — раздел подкачки (swap).

Выбираем диск для установки **"Finish partitioning and write changes to disk"**.
Жмем **"Continue"**.

После нажатия **Continue** начнётся **форматирование диска** и **установка системы**.
Все данные на диске будут **безвозвратно удалены**.

| Название                             | Описание                                                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| Guided partitioning                  | Позволяет ещё раз запустить мастер автоматической разметки (если вы выбрали не ту схему)                                       |
| Configure software RAID              | Позволяет объединить несколько физических дисков в один массив для отказоустойчивости (зеркалирование) или увеличения скорости |
| Configure the Logical Volume Manager | Даёт возможность создать гибкие логические тома, которые можно расширять без переустановки системы                             |
| Configure encrypted volumes          | Позволяет зашифровать отдельные разделы (или весь диск) для защиты данных от кражи                                             |
| Configure iSCSI volumes              | Подключение удалённых дисков по сети (как сетевой жёсткий диск)                                                                |

| Название                                          | Описание                                                                                                                                                  |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Undo changes to partitions                        | Отменяет все изменения, которые вы сделали на этапе разметки диска                                                                                        |
| **Finish partitioning and write changes to disk** | Применяет **все** изменения разделов на физическом диске. Данные на выбранном диске будут **безвозвратно удалены**, после чего начнётся установка системы |

##### Окружения рабочего стола (Desktop Environments)

| Название                       | Описание                                                                        | Требования к ресурсам     |
| ------------------------------ | ------------------------------------------------------------------------------- | ------------------------- |
| **Debian desktop environment** | Базовый набор для графического интерфейса (содержит GNOME по умолчанию)         | Средние                   |
| **GNOME**                      | Современное, красивое окружение. Похоже на macOS. Стандартный выбор для Debian. | Высокие (2-4 ГБ RAM)      |
| **Xfce**                       | Лёгкое, быстрое окружение. Похоже на Windows XP/7.                              | Низкие (512 МБ RAM)       |
| **GNOME Flashback**            | Классический GNOME со старой панелью (как в Windows 7)                          | Средние                   |
| **KDE Plasma**                 | Очень красивое, гибкое окружение. Похоже на Windows 10/11.                      | Высокие (2-4 ГБ RAM)      |
| **Cinnamon**                   | Удобное окружение, похожее на Windows. Разработано для Linux Mint.              | Средние                   |
| **MATE**                       | Продолжение классического GNOME 2. Легче, чем современный GNOME.                | Низкие (1 ГБ RAM)         |
| **LXDE**                       | Очень лёгкое окружение. Минималистичное.                                        | Очень низкие (256 МБ RAM) |
| **LXQt**                       | Современная версия LXDE на Qt. Лёгкое и красивое.                               | Низкие (512 МБ RAM)       |
##### Серверное ПО (Server Software)

| Название       | Описание                                                                   |
| -------------- | -------------------------------------------------------------------------- |
| **web server** | Устанавливает Apache + дополнительные модули для веб-сервера               |
| **SSH server** | **Рекомендую оставить** — позволяет подключаться к серверу удалённо по SSH |
##### Системные утилиты (System Utilities)

| Название                      | Описание                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **standard system utilities** | **Оставьте включённым** — набор стандартных программ (текстовые редакторы, файловые менеджеры, сетевые утилиты, менеджер пакетов и т.д.) |
##### Дополнительно (Advanced)

| Название                                   | Описание                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------- |
| **Choose a Debian Blend for installation** | Установка специализированных наборов ПО (научные, образовательные, медицинские и т.д.) |
