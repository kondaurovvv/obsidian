Это практическая модель, на которой построен весь современный интернет. Она проще и состоит из **4 уровней**, объединяя некоторые уровни OSI.

- **Прикладной (Application):** Объединяет прикладной, представительский и сеансовый уровни OSI (HTTP, FTP, DNS).
- **Транспортный (Transport):** Отвечает за связь между приложениями (TCP, UDP).
- **Сетевой / Межсетевой (Internet):** Отвечает за доставку пакетов по сети с помощью IP-адресов (IP).
- **Доступа к сети (Network Access):** Объединяет канальный и физический уровни OSI (Ethernet, Wi-Fi, драйверы).

| №     | Уровень (Название)                    | Главная задача                                                      | Примеры (Протоколы / Оборудование)               | Соответствие уровням OSI                           |
| ----- | ------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------ | -------------------------------------------------- |
| **4** | **Прикладной** _(Application)_        | Взаимодействует с приложениями, форматирует и шифрует данные.       | HTTP, HTTPS, FTP, DNS, SMTP, SSH, TLS            | 7, 6, 5 (Прикладной, Представительский, Сеансовый) |
| **3** | **Транспортный** _(Transport)_        | Управляет передачей данных между процессами и делит их на сегменты. | TCP, UDP                                         | 4 (Транспортный)                                   |
| **2** | **Сетевой / Межсетевой** _(Internet)_ | Маршрутизирует пакеты данных по IP-адресам через разные сети.       | IP (IPv4/IPv6), ICMP, Роутеры (Маршрутизаторы)   | 3 (Сетевой)                                        |
| **1** | **Доступа к сети** _(Network Access)_ | Кодирует данные в сигналы и передает их по физической среде.        | Ethernet, Wi-Fi, MAC-адреса, Кабели, Коммутаторы | 2, 1 (Канальный, Физический)                       |
