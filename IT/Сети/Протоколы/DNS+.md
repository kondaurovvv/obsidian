#### Зачем нужен DNS?
- Система DNS позволяет преобразовать имена в компьютеров в IP-адрес.
	- www.yandex.ru -> 77.88.55.66;
- Преимущества DNS:
	- Понятные человеку имена;
	- возможность менять сетевую инфраструктуру.

#### Утилита nslookup
- nslookup yandex.ru;
- Другие утилиты (Linux):
	- host;
	- dig.

**Пример**
Сервер:  dc1.imm.uroran.ru
Address:  192.168.15.1

Не заслуживающий доверия ответ:
		yandex.ru
Addresses:  2a02:6b8:a::a
          5.255.255.77
          77.88.55.88
          77.88.44.55

#### Файл /etc/hosts
- Файл содержит имена компьютеров их адреса;
	- Linux/Unix: /etc/hosts;
	- Windows: С:\Windows\System32\drivers\etc\hosts
- **Пример**:
	- 102.54.94.97   server;
	- 38.25.63.10   my-client.
- Недостатки:
	- Быстро увеличивается размер;
	- Сложность вносить изменения;
	- Возможны конфликты имен.

#### Особенности DNS
- Распределённая система:
	- Нет единого сервера, на котором описываются имена хостов;
- Делегирование ответственности:
	- Пространство имен разделено на отдельные части - домены;
	- За каждый домен отвечает отдельная организация.
- Надежность:
	- Дублирование серверов DNS.

#### Структура доменного имени
- **Пример**:
	- ==www== . ==urfu== . ==ru== :
		- ==ru== - Домен верхнего уровня;
		- ==urfu== - Домен второго уровня;
		- ==www== - Имя компьютера.

#### Можно обойтись и без DNS
- Можно указывать адреса в URL в квадратных скобках:
	- Например, http://user:password@[2001:DB8:B16:B5::1]:80/folder .
- Обработку файла host никто не отменял
- Windows разрешает транскрипцию без обращения к DNS.
