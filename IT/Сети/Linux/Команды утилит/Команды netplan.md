По умолчанию утилита netplan создает конфигурационный файл.
```bash
/etc/netplan/01-network-manager-all.yaml
```

Преобразует конфигурационные YAML-файлы (из /etc/netplan/) в физические конфигурационные файлы для конкретного бэкенда (systemd-networkd или NetworkManager) и сохраняет их в каталог /run/netplan/.
```bahs
netplan generate
```

Безопасный способ применить изменения сетевой конфигурации. (проверяет синтаксис и конфигурации)
```bash
netplan try
```

Применяет изменения немедленно и навсегда без возможности автоматического отката.
```bash
netplan apply
```
