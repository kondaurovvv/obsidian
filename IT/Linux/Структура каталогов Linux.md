| Каталог           | Содержимое                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------- |
| ==**/**==         | Корень файловой системы. Начало всех путей.                                              |
| ==**/bin**==      | Базовые команды пользователя (`ls`, `cp`, `mv`). Ссылка на `/usr/bin`.                   |
| ==**/sbin**==     | Системные команды для администратора (`fdisk`, `mkfs`, `reboot`). Ссылка на `/usr/sbin`. |
| ==**/lib**==      | Базовые системные библиотеки. Ссылка на `/usr/lib`.                                      |
| **/lib64**        | 64-битные системные библиотеки. Ссылка на `/usr/lib64`.                                  |
| ==**/boot**==     | Файлы загрузчика (GRUB), ядро (`vmlinuz`) и initramfs.                                   |
| ==**/etc**==      | **Настройки системы и всего ПО** (`passwd`, `fstab`, `ssh/`, `nginx/`).                  |
| ==**/home**==     | Личные файлы и настройки всех рядовых пользователей (`/home/user/`).                     |
| ==**/root**==     | Домашняя папка суперпользователя root. (Вынесена из `/home` для безопасности).           |
| **/usr**          | **Основные установленные программы**, библиотеки, документация и иконки.                 |
| ↳ `/usr/bin`      | Исполняемые файлы программ (большинство команд).                                         |
| ↳ `/usr/sbin`     | Системные утилиты для администрирования.                                                 |
| ↳ `/usr/lib`      | Библиотеки для программ из `/usr/bin`.                                                   |
| ↳ `/usr/local`    | ПО, установленное администратором вручную (из исходников).                               |
| ↳ `/usr/share`    | Общие данные (документация `man`, шрифты, локали, иконки).                               |
| ↳ `/usr/include`  | Заголовочные файлы для компиляторов C/C++.                                               |
| ↳ `/usr/src`      | Исходные коды (например, ядра Linux).                                                    |
| ==**/opt**==      | Стороннее проприетарное ПО (Chrome, TeamViewer, игры). Каждое в своей подпапке.          |
| **/var**          | **Логи и часто меняющиеся данные** (кэш, очереди печати, почта).                         |
| ↳ `/var/log`      | **Системные логи** (журналы событий и ошибок).                                           |
| ↳ `/var/cache`    | Кэш программ (можно безопасно удалять).                                                  |
| ↳ `/var/spool`    | Очереди заданий (печать, непрочитанная почта).                                           |
| ↳ `/var/lib`      | Базы данных служб (MySQL, PostgreSQL, Docker).                                           |
| ↳ `/var/tmp`      | Временные файлы, которые **НЕ удаляются** при перезагрузке.                              |
| ==**/tmp**==      | Временные файлы (полностью **чистятся при перезагрузке**). Доступно всем.                |
| ==**/run**==      | Временные данные с момента запуска системы (PID-файлы, сокеты). Хранится в ОЗУ.          |
| ==**/proc**==     | **Виртуальная информация о процессах и ядре** (в ОЗУ).                                   |
| ↳ `/proc/cpuinfo` | Данные о процессоре.                                                                     |
| ↳ `/proc/meminfo` | Данные об оперативной памяти.                                                            |
| ↳ `/proc/[PID]/`  | Информация о конкретном процессе по его ID.                                              |
| ==**/sys**==      | Виртуальная информация об устройствах, драйверах и питании (ACPI).                       |
| ==**/dev**==      | **Файлы устройств** (диски, терминалы, порты).                                           |
| ↳ `/dev/sda`      | Первый жесткий диск (SATA/SCSI).                                                         |
| ↳ `/dev/nvme0n1`  | SSD-диск с интерфейсом NVMe.                                                             |
| ↳ `/dev/tty`      | Терминалы.                                                                               |
| ↳ `/dev/null`     | "Черная дыра" — сброс данных.                                                            |
| ↳ `/dev/zero`     | Генератор нулевых байтов.                                                                |
| ↳ `/dev/random`   | Генератор случайных чисел.                                                               |
| ↳ `/dev/shm`      | Разделяемая память (tmpfs, быстрее диска).                                               |
| ==**/mnt**==      | Временная папка для **ручного** монтирования дисков.                                     |
| ==**/media**==    | Автоматическое монтирование съемных носителей (флешек, DVD).                             |
| ==**/srv**==      | Данные, обслуживаемые серверами (обычно файлы веб-сайтов).                               |
