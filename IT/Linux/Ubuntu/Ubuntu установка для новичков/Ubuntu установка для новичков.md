#### Установка
![[U-1.png|900]]
Выбираем **"Try or Install Ubuntu"** -  красивый интерфейс с мышкой.
Жмем **"Enter"**.

![[U-2.png|900]]
Выбираем язык.
Жмем **"Next"**.

![[U-3.png|900]]
Это экран настройки специальных возможностей для людей с ограниченными возможностями.
Жмем **"Next"**.

| Раздел                                         | Описание                                                                                                                           | Что можно настроить                                                                                                                                                                                                       |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Seeing** (Зрение)                            | Настройки для людей с нарушениями зрения. Позволяет сделать изображение на экране более удобным для восприятия.                    | — Экранный диктор (озвучивание текста на экране)  <br>— Увеличение масштаба экрана  <br>— Высокая контрастность (изменение цветовой схемы)  <br>— Крупный шрифт  <br>— Инверсия цветов                                    |
| **Hearing** (Слух)                             | Настройки для людей с нарушениями слуха. Позволяет заменить звуковые сигналы визуальными.                                          | — Визуальные оповещения (мигание окна или экрана вместо звукового сигнала)                                                                                                                                                |
| **Typing** (Печать)                            | Настройки для людей с нарушениями моторики или координации движений. Облегчает набор текста на клавиатуре.                         | — Залипание клавиш (зажатие клавиши-модификатора, например Shift, работает как удержание)  <br>— Медленные клавиши (задержка перед регистрацией нажатия)  <br>— Отскок клавиш (игнорирование случайных повторных нажатий) |
| **Pointing and clicking** (Указание и нажатие) | Настройки для людей, которым сложно управлять мышью. Позволяет управлять курсором с клавиатуры или изменять поведение кнопок мыши. | — Управление курсором с помощью цифровой клавиатуры (эмуляция мыши)  <br>— Изменение порядка кнопок мыши (для левшей)  <br>— Эмуляция щелчка правой кнопки мыши                                                           |
| **Zoom** (Масштабирование)                     | Настройка увеличительного стекла для экрана. Позволяет увеличивать отдельные участки экрана.                                       | — Включение/выключение увеличительного стекла  <br>— Настройка степени увеличения                                                                                                                                         |

![[U-4.png|900]]
Выбираем раскладку клавиатуры.
Жмем **"Next"**.

![[U-5.png|900]]
Выбираем **"Use wired connection"**.
Жмем **"Next"**.

| Элемент                                                          | Описание                                                                                                                                                                                                |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Use wired connection** (Использовать проводное подключение)    | Подключение через сетевой кабель (Ethernet). Если кабель вставлен в компьютер, интернет появится автоматически.                                                                                         |
| **No Wi-Fi devices detected** (Wi-Fi устройства не обнаружены)   | Система не нашла встроенный или внешний Wi-Fi адаптер. Это может означать, что:  <br>— В компьютере нет Wi-Fi модуля  <br>— Требуются дополнительные драйверы (обычно для некоторых моделей Wi-Fi карт) |
| **Do not connect to the Internet** (Не подключаться к интернету) | Установка будет проходить без интернета. Система установит только базовый набор программ. Дополнительные драйверы и обновления не скачаются.                                                            |

![[U-6.png|900]]
Выбираем **"Install Ubuntu"**.
Жмем **"Next"**.

|Элемент|Описание|
|---|---|
|**Install Ubuntu** (Установить Ubuntu)|Полная установка системы на жесткий диск. Вы уже прошли все предыдущие шаги, и сейчас начнется процесс копирования файлов.|
|**Try Ubuntu** (Попробовать Ubuntu)|Загрузка Ubuntu в "живом" режиме (Live USB). Вы сможете ознакомиться с системой, не внося изменений на жесткий диск. Все изменения будут жить только в оперативной памяти и исчезнут после перезагрузки.|
