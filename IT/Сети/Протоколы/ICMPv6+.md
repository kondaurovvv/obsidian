**ICMPv6** (Internet Control Message Protocol for IPv6) — это ==важный служебный протокол сетевого уровня, созданный для работы с протоколом [IPv6](https://ru.wikipedia.org/wiki/ICMPv6)==. Он передает сообщения об ошибках, помогает проверять связь (например, в утилите ping) и заменяет сразу несколько старых протоколов из мира IPv4.

#### Internet Control Message Protocol v6
- Неотъемлемая часть протокола IPv6;
- Код вложения (Next Header) - 58:
	- Использует тот же формат заголовка, что и ICMP для IPv4;
	- Всегда последний заголовок, нет поля Next Header;
	- Контрольная сумма Internet Checksum считается от псевдозаголовка;
- Решает почти все сервисные задачи:
	- Типичные для ICMP задачи (оповещение об ошибках);
	- Обнаружение канальных адресов соседей (вместо ARP);
	- Базовая автонастройка конечных узлов (вместо DHCP);
	- Управление мультикастом (вместо IGMP).
