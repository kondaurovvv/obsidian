Основная команда. Отслеживает маршрут до указанного узла (доменное имя или IP-адрес).
```bash
traceroute <узел>
```

Отображает IP-адреса узлов без попытки преобразовать их в доменные имена. Это ускоряет работу.
```bash
traceroute -n <узел>
```

Использует ICMP-пакеты для зондирования (по умолчанию используются UDP-пакеты). Может быть полезно, если UDP-пакеты блокируются файрволом.
```bash
traceroute -I <узел>
```

Использует TCP-пакеты (например, с портом 80). Помогает обходить некоторые типы сетевых экранов.
```bash
traceroute -T <узел>
```

Устанавливает максимальное количество прыжков (hop) для зондирования. По умолчанию 30.
```bash
traceroute -m <число> <узел>
```

Указывает порт назначения для отправки зондов. По умолчанию используется диапазон от 33434 до 33534.
```bash
traceroute -p <порт> <узел>
```
