**ICMP** (Internet Control Message Protocol) — это ==служебный протокол сети (уровня IP), который используется для диагностики соединений и передачи сообщений об ошибках==. Он не передаёт сами пользовательские данные, а помогает маршрутизаторам и компьютерам сообщать о проблемах (например, если узел недоступен). 

- Internet Control Message Protocol;
- RFC 792, неотъемлемая часть IPv4;
- Сервисный протокол без контроля доставки;
- Не передает пользовательских данных.

|Английское название|Русский перевод|Размер (бит)|Краткое описание|
|---|---|---|---|
|**Type**|**Тип**|8|Определяет тип ICMP-сообщения. Основные значения: **0** – эхо-ответ (**Echo Reply**), **8** – эхо-запрос (**Echo Request**), **3** – пункт назначения недостижим (**Destination Unreachable**), **5** – перенаправление (**Redirect**), **11** – превышено время (**Time Exceeded**), **12** – проблема с параметром (**Parameter Problem**) и другие.|
|**Code**|**Код**|8|Уточняет причину для данного типа. Например, для типа «пункт назначения недостижим» (**Destination Unreachable**) коды: **0** – сеть недостижима (**Network Unreachable**), **1** – хост недостижим (**Host Unreachable**), **3** – порт недостижим (**Port Unreachable**) и т.д.|
|**Checksum**|**Контрольная сумма**|16|16-битное поле, вычисляемое как дополнение до единицы от суммы всех 16-битных слов ICMP-сообщения (начиная с поля «Тип»). Перед расчётом поле обнуляется. Используется для проверки целостности пакета.|
|**Identifier** (опционально)|**Идентификатор**|16|Присутствует только в сообщениях **эхо-запрос / эхо-ответ** (**Echo Request / Echo Reply**, типы 8 и 0). Обычно содержит идентификатор процесса-отправителя, чтобы сопоставлять ответы с запросами.|
|**Sequence Number** (опц.)|**Порядковый номер**|16|Также только для эхо-сообщений. Позволяет нумеровать пакеты в серии, чтобы отслеживать потери, задержки и порядок прибытия.|
|**Data** (переменная часть)|**Полезные данные**|переменный|Содержимое зависит от типа сообщения:  <br>• Для **эхо-запросов и ответов** (**Echo Request/Reply**) – пользовательские данные (обычно заполняются произвольными байтами, используются для расчёта времени кругового пути – RTT).  <br>• Для **сообщений об ошибках** (типы «пункт назначения недостижим» (**Destination Unreachable**), «превышено время» (**Time Exceeded**), «проблема с параметром» (**Parameter Problem**) и др.) – включает **IP-заголовок исходного пакета** и **первые 8 байт его полезной нагрузки** (чтобы идентифицировать вызвавшее ошибку соединение).|
