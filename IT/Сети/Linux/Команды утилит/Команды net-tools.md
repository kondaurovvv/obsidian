Показывает настройки всех активных сетевых интерфейсов (IP, MAC, MTU, статистика). Если добавить имя интерфейса — покажет параметры только для него.
```bash
ifconfig
```

Активирует (поднимает) указанный сетевой интерфейс.
```
ifconfig <имя интерфейса> up
```

Деактивирует (опускает) указанный сетевой интерфейс.
```bash
ifconfig <имя интерфейса> down
```

Назначает интерфейсу IP-адрес и маску подсети в точечно-десятичном формате (например, 255.255.255.0).
```bahs
ifconfig <имя интерфейса> <ip адрес> netmask <маска в точечно-десятичном формате>
```

Назначает интерфейсу IP-адрес с маской в виде префикса (например, /24). Это сокращённая форма (без ключевого слова netmask).
```bash
ifconfig <имя интерфейса> <ip адрес>/<маска в виде префикса>
```
