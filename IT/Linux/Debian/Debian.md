#### Установка
![[D1.png|900]]
Выбираем **"Graphical install"** -  красивый интерфейс с мышкой.

![[D2.png|900]]
Выбираем язык.

![[D3.png|900]]
Выбираем страну.

![[D4.png|900]]
Выбираем раскладку клавиатуры.

![[D5.png|900]]
Вводим имя компьютера.

![[D6.png|900]]
Вводим имя домена или оставляем пустым если нет домена.

![[D7.png|900]]
Вводим пароль от **Root** пользователя.

![[D8.png|900]]
Вводим в поле **"Full name for the new user"** наше полное имя. (Ivan)

![[D9.png|900]]
Вводим в поле **"Username for your account"** короткое имя. (ivan)

![[D10.png|900]]
Вводим пароль от **ivan** пользователя.

![[D11.png|900]]
Выбираем часовой пояс.

![[D12.png|900]]
Выбираем по необходимости, но для начинающих **Guided - use entire disk**.

| Вариант                                           | Описание                                                                             |
| ------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Guided - use entire disk                          | Стандартная разметка — система сама разобьёт диск на разделы (корневой, swap, /home) |
| Guided - use entire disk and set up LVM           | Гибкая разметка с LVM (можно изменять размеры разделов позже)                        |
| Guided - use entire disk and set up encrypted LVM | LVM + шифрование всего диска                                                         |
| Manual                                            | Ручная разметка (создание разделов вручную)                                          |

![[D13.png|900]]
Выбираем диск для установки.

![[D14.png|900]]

| Вариант                            | Описание                                                           | Для кого                                     |
| ---------------------------------- | ------------------------------------------------------------------ | -------------------------------------------- |
| **All files in one partition**     | Всё в одном разделе (корневой `/` + `/home` внутри)                | Cамый простой и понятный                     |
| Separate /home partition           | Отдельный раздел для домашних папок (удобно при переустановке)     | Для тех, кто часто переустанавливает систему |
| Separate /home, /var, and /tmp     | Разделение системных логов и временных файлов на отдельные разделы | Для серверов с высокой нагрузкой             |
| Separate /var and /srv, swap < 1GB | Для серверов (веб-серверы, базы данных)                            | Для продакшн-серверов                        |
| Small-disk (< 10GB)                | Оптимизация для маленьких дисков                                   | Для старых/слабых компьютеров                |

![[D15.png|900]]

| Название                             | Русский перевод             | За что отвечает                                                                                                                |
| ------------------------------------ | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Guided partitioning                  | Автоматическая разметка     | Позволяет ещё раз запустить мастер автоматической разметки (если вы выбрали не ту схему)                                       |
| Configure software RAID              | Настройка программного RAID | Позволяет объединить несколько физических дисков в один массив для отказоустойчивости (зеркалирование) или увеличения скорости |
| Configure the Logical Volume Manager | Настройка LVM               | Даёт возможность создать гибкие логические тома, которые можно расширять без переустановки системы                             |
| Configure encrypted volumes          | Настройка шифрования        | Позволяет зашифровать отдельные разделы (или весь диск) для защиты данных от кражи                                             |
| Configure iSCSI volumes              | Настройка iSCSI-томов       | Подключение удалённых дисков по сети (как сетевой жёсткий диск)                                                                |

| Название                                      | Русский перевод                                 | За что отвечает                                                                                                                                           |
| --------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Undo changes to partitions                    | Отменить изменения в разделах                   | Отменяет все изменения, которые вы сделали на этапе разметки диска                                                                                        |
| Finish partitioning and write changes to disk | Завершить разметку и записать изменения на диск | Применяет **все** изменения разделов на физическом диске. Данные на выбранном диске будут **безвозвратно удалены**, после чего начнётся установка системы |
Показано, какие разделы будут созданы:
- **#1 primary (40.7 GB)** — корневой раздел `/` с файловой системой ext4
- **#5 logical (2.2 GB)** — раздел подкачки (swap)

После нажатия **Continue** начнётся **форматирование диска** и **установка системы**
Все данные на диске будут **безвозвратно удалены**
Жмем **"Continue"**.

![[D16.png|900]]
Это **финальное подтверждение** перед записью разметки на диск.
Жмем **"Continue"**.

![[D18.png|900]]

| ------- | ---------------------------------------------------------------------- |

Выбрать **страну**, в которой находится ближайший к вам сервер (зеркало) с пакетами Debian.

![[D21.png|900]]
**Оставьте поле пустым** (ничего не вводите) и нажмите **`Continue`**

![[D22.png|900]]
Это настройка **участия в сборе статистики** использования пакетов.
Выбираем **NO**
