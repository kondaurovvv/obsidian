Формат любой команды - "команда" "ключ" "аргументы".
**Пример:** ls -l Documents/

Горячий клавиши:
- **Shift + PageUp** — прокрутить экран вверх;
- **Shift + PageDown** — прокрутить экран вниз;
- **Tab** — дописать имя команды, путь или файл автоматически;
- **Двойной Tab** — показать все возможные варианты, если их несколько;
- **Стрелка Вверх** — показать предыдущую команду из истории;
- **Стрелка Вниз** — вернуться к более поздней команде;
- **Ctrl + R** — быстрый поиск по истории. Начните вводить буквы, и Bash найдет прошлую команду;
- **Ctrl + L** — очищает консоль;

Специальные знаки:
- * - Любое количество символов;
- ? - Ровно один любой символ;

- ls - показывает содержимое какого либо каталога;
	- Ключи:
		- --help - помощь;
		- -l - Выводит список файлов в виде **подробной таблицы**.
		- -a - Показывает **вообще все** файлы и папки, включая **скрытые**.
- pwd - показывает текущую директорию:
	- Ключи:
		- --help - помощь;
- touch - создание файла:
	- Ключи:
		- --help - помощь;
- mkdir - создание директорий:
	- Ключи:
		- --help - помощь;
		- -p - 
- cd - смена директорий (без аргументов отправляет в домашнюю директорию):
	- Ключи:
		- --help - помощь;
- rm - удаления файла:
	- Ключи:
		- --help - помощь;
		- -r - удалить рекурсивно;
- rmdir - удаления директорий:
	- Ключи:
		- --help - помощь;
- cp - копирует файлы и директории;
	- Ключи:
		- --help - помощь;
		- -r - копировать рекурсивно (для копирования директорий с содержимым);
- mv - перемещения файлов и директорий и переименования:
	- Ключи:
		- --help - помощь;
- type - проверяет тип команды:
	- Ключи:
		- --help - помощь;
- whereis - показывает, где на диске лежит сама программа:
	- Ключи:
		- --help - помощь;
- echo - просто печатает на экране всё, что вы напишете после неё.
	- Ключи:
		- --help - помощь;
- which - отвечает на вопрос: «Какой именно файл запустится, если я введу имя этой команды?».
	- Ключи:
		- --help - помощь;
- who - показывает кто сейчас работает на это сервере:
	- Ключи:
		- --help - помощь;
- man - страница руководства;
	- Ключи:
		- --help - помощь;
